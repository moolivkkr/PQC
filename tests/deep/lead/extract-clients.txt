## 1. H1 and lead paragraphs
H1: Mobile, desktop and CLI clients

Each client's own TLS stack decides what it offers: the OS stack on iOS, macOS and Windows; BoringSSL in Chrome; NSS in Firefox; OpenSSL, GnuTLS or LibreSSL in command-line tools; Go's crypto/tls in kubectl, helm and terraform. A client only gets PQ if the server also offers it, so most of these clients start using PQ against your estate only after the front doors run a PQ policy ([Load balancers], [Edge and API front doors]). Every client below still connects to classical servers.

Tested = run here on 2026-11-14 against a PQ-only server (openssl s_server -groups X25519MLKEM768 -tls1_3, OpenSSL 3.5.7) and a classical-only server (-groups X25519). Every Tested client also reached the classical server. Scripts and output: deep/hosts/run-hosts*.sh and run-hosts*.out in the work dir.
