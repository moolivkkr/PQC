## 1. H1 and lead paragraphs
H1: AWS service endpoints: KMS, SSM, Secrets Manager and others

AWS owns the server side of every AWS API endpoint. On the listed services, the endpoint prefers X25519MLKEM768 whenever the client offers it ("transparent"), so the work is on the client: the SDK, the AWS CLI, or the AWS agent that makes the call. Services AWS has not listed (Systems Manager, Lambda Invoke, CloudWatch, Step Functions, ECS, EKS, the EC2 API) should be treated as classical even from a PQ client. Source: AWS PQ readiness (confidentiality), re-read 2026-11-14 (the page has no date; footer © 2026).

Re-read 2026-11-14. "Transparent" means nothing to configure on the AWS side.
