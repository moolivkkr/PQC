## 1. H1 and lead paragraphs
H1: Web servers, reverse proxies and app servers (self-managed)

Every OpenSSL 3.5, Go 1.24+ and JDK 25 server tested here negotiates X25519MLKEM768 on both legs with one or two lines of config; Envoy and anything under the Amazon Linux 2023 crypto policy stay classical until you set the group list. 110 checks across 20 server configurations, run 2026-11-14.

The TLS library linked into the server binary decides, separately for each leg. Inbound (client to server) uses the listener's group list. Upstream (server to backend: proxy_pass, ProxyPass, HAProxy server lines, Envoy clusters) uses the proxy's client-side group list.
