Post-quantum TLS on AWS · 07

KEY MESSAGE: PQ is decided by the TLS library of whoever starts each hop, not by the compute type and not by the certificate. • Inbound: the load balancer’s security policy decides the client leg. Behind it, the container’s language runtime decides the target leg. • Our own code, on any compute: the language runtime and its config decide. That’s where almost all of the work is. • Calls to AWS APIs are PQ today from a fixed client, and CloudTrail records the key exchange, so we can prove them. • The orange dashed line is the blind spot: calls to non-AWS services from Lambda and Fargate. No AWS log shows the group, so we carry them on inventory until a sensor or app-side log exists.
