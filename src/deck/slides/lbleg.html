Two policies, two legs. A non-PQ listener policy leaves every client classical, and a classical container keeps the ALB-to-target leg classical. The listener leg needs real AWS: LocalStack ignores the policy.

Post-quantum TLS on AWS · 12 · 32 target-leg cases, modelled on LocalStack

KEY MESSAGE: Setting a PQ policy on the ALB fixes the client leg only; the container behind it decides the second leg. • The ALB re-encrypts to the target. In that hop the ALB is the client and our container is the server, so the container’s TLS library decides. • Each row shows the same container failing without the fix and passing with it: 32 cases, all as expected. • The newest images need nothing: trixie, node:24, Go 1.26, Corretto 25.0.5, .NET 10 Alpine. • Caveat: LocalStack doesn’t apply listener policies, so the listener leg is in the Phase 0 sandbox test on real AWS.
