Post-quantum TLS on AWS · 08 · Detail per language, version and compute type: the guide’s language tabs

KEY MESSAGE: For every language the fix is one setting, one file, a rebuild or a version bump, and each is tested. • Go is the easiest: its own TLS library, so rebuild with 1.26 and set the go line. Most misses are an old go line with a new toolchain. • Python, Node.js and .NET use OpenSSL: on Lambda and AL2023 one config file turns PQ on; the newest base images are already PQ. • Java is the one that needs a kit until JDK 25: a Bouncy Castle agent plus a security file, tested from JDK 8 to 21. • The one rule for every team: remove code that pins old groups or TLS 1.2. CI flags it. • 437 client cases in total, all passing.
