The problem

Why act now

Harvest now, decrypt later

Traffic recorded today can be decrypted once a large quantum computer exists. Data that must stay private for years is exposed now.

Classical by default

On Lambda and the AL2023 images, Python, Node.js, .NET and Java below 25 still negotiate classical X25519 unless we change something.

It fails silently

A connection that stays classical raises no error: the handshake falls back. Only logs and inventory show it.

Goal: every TLS connection we own negotiates X25519MLKEM768, with the certificates we have today, and we can prove it from logs.
