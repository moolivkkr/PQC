KEY MESSAGE: Fixing a workload once isn’t enough. Five layers stop a classical setting from coming back, and every rule has been run against good and bad samples. • Organisation: an SCP denies non-PQ load balancer and API Gateway REST policies at the API, before anything is created. • Account: AWS Config rules and the AWS PQC readiness scanner sample flag drift. Note that Security Hub ELB.17 passes non-PQ policies, so it isn’t PQ coverage. • Pipeline: cfn-guard (14 rules), the CloudFormation Guard Hook, conftest on Terraform plans, Dockerfiles and SBOMs, Checkov, and Go and JDK binary checks. • Cluster: Kyverno 1.20 ValidatingPolicy for ALB Ingress, NLB Services, ingress-nginx, Istio and Pod variables. • Runtime: CloudTrail alarm on non-ML-KEM calls, ELB log reports, Zeek. • Honest status: rules tested in containers on sample inputs, never yet applied to an AWS account. That is in Phase 0.
