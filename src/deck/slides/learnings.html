KEY MESSAGE: A guide nobody tests is a guide with errors in it. These six would each have reached production. • Python: the bridge for old Lambda runtimes was missing one package, so every request would have failed. Not a PQ failure, a total outage. • Node.js 20: we said nothing helps. On AL2023 it does, because it links the system OpenSSL. • Java 8: the kit alone broke every HttpsURLConnection handshake. One flag fixes it, and the layer now sets it. • .NET: the worst kind of bug. The guardrail approved functions that were still classical, because the layer had no .NET branch. • Takeaway: this is why every number in the deck comes from a test that can fail.
