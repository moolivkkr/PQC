KEY MESSAGE: For ALB and NLB, PQ is one setting on the listener, but the tools we use for infrastructure as code pick the old policy unless we name the new one. • The certificate has nothing to do with key exchange. We keep every ACM certificate. • The trap: CloudFormation, the CLI and CDK default to ELBSecurityPolicy-2016-08. Only the console defaults to the PQ policy. So every template has to name the policy, and the SCP makes that mandatory. • The Res-PQ policy is hybrid for TLS 1.3 clients and still serves TLS 1.2 clients, so nothing breaks. Once logs show no TLS 1.2 traffic, move to the TLS 1.3-only PQ policy. • Classic Load Balancers can’t do TLS 1.3 at all: they move to ALB or NLB. • Proof is in the logs: the tls_keyexchange field per connection.
