KEY MESSAGE: Guardrails tighten in steps, so teams see warnings before anything blocks them, and any step can be undone in minutes. • Week 0: turn on detection and run every pipeline check in warn mode. • Week 2: block new risk: the SCP on sandbox and new-workload OUs, and the pipeline fails only on resources in the change. • Week 6: fail every resource in CI; anything left gets an exception. • Week 8: the SCP on all workload OUs, once Config shows nothing non-compliant outside the register. • Then: the classical share per load balancer trends down to the exception list. • In the rollout plan this runs as Phase 2 (warn) and Phase 5 (enforce).
