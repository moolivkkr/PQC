KEY MESSAGE: Same certificates, quantum-safe key exchange, and we can prove it workload by workload. • Recap in three words: tested, small, provable. • Repeat the ask: the sandbox account, the windows, and a lead per role; the three policy decisions can follow in a few weeks. LIKELY QUESTIONS: • “Do we need new certificates?” No. Only key exchange changes. ML-DSA certificates are a later, separate step. • “Will anything break?” Hybrid falls back to classical for peers without ML-KEM, and every fix is removed by deleting one file or variable. • “Why not wait for AWS to make it the default?” Lambda’s managed runtimes and AL2023 still default to classical, and the deprecated runtimes can’t be changed after 31 August 2027. • “Has this run on real AWS?” Not yet. LocalStack and Docker only, on arm64. Phase 0 is that test. • “What about traffic we can’t see?” Lambda and Fargate to non-AWS services stays on inventory as posture-only until an app-side log exists.
