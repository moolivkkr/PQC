KEY MESSAGE: Go is the simplest language: its own TLS stack, so the compute type and base image don’t matter. Only the toolchain and the go line do. • Lambda, Fargate, ECS on EC2 and EC2 all behave the same: a binary built with Go 1.24+ and a go line of 1.24+ is PQ. • The trap is the go line: Go 1.27 with go 1.23 in go.mod is classical. CI checks the go line. • No rebuild possible? GODEBUG=tlsmlkem=1 in the function, task or unit environment turns it on. • OS crypto policies, OPENSSL_CONF and our layers have no effect on Go; we tested that so nobody wastes time on it. • FIPS: the native Go FIPS module (GOFIPS140) is PQ; the old boringcrypto build panics with fips140=on. • EKS was not run in the emulator; it runs the same images as ECS, so we expect the same result but haven’t tested it.
