Post-quantum TLS on AWS · 14 · Guide: Infrastructure tabs; AWS support checked 2026-11-16

KEY MESSAGE: Inside the platform, PQ is mostly an upgrade or one config line that we control; AWS-managed data services are the main gap. • Mesh: Linkerd 2.19+ is PQ by default. Istio 1.27+ has COMPLIANCE_POLICY=pqc, but it is PQ-only and breaks non-PQ peers, so it comes last. ECS Service Connect has no setting. • Databases: RDS and Aurora depend on the engine version; drivers must be PQ-capable too. RDS Proxy, ElastiCache, MSK and OpenSearch can’t do it yet. • Hosts: AL2023 gets DEFAULT:PQ through SSM; Debian 13 and Ubuntu 26.04 are on for OpenSSL programs. Amazon Linux 2 has to be migrated. • Self-managed servers: set the groups on both the listener and the upstream side. Envoy 1.40+ is PQ by default; we tested 1.40.2. • Certificates: ML-DSA is a separate, later step, piloted on internal mutual TLS. ACM and the load balancers can’t serve ML-DSA yet.
