KEY MESSAGE: We can prove most of the estate from logs AWS already writes; the rest we track honestly as posture. • CloudTrail records tlsDetails.keyExchange for every AWS API call. That covers the biggest share of outbound traffic. • ALB and NLB access logs record the key exchange on the client leg. • On EC2 and containers on EC2, an egress sensor or Zeek on VPC Traffic Mirroring sees the group in the handshake. • Lambda and Fargate to non-AWS peers is the blind spot: there is nowhere to mirror. We count those as posture-only, not as done. • In the e2e tests the CloudWatch filter and the server-side log caught every classical handshake in the full run of 16 November; one earlier run lost a log line in LocalStack under load. CloudTrail and ELB log fields are AWS-documented, not yet tested on real AWS.
