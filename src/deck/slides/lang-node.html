KEY MESSAGE: Node carries its own OpenSSL, so the Node version decides: 22.20+ and 24.5+ are PQ everywhere except Lambda, where one config file fixes it. • On Lambda, AWS’s bootstrap sets its own OpenSSL config that removes the PQ group. Our config file in the pq-tls layer puts it back. • Node 18 and 20 bundle OpenSSL 3.0: no setting helps. Upgrade; the pq-egress extension is a bridge for calls that must be PQ sooner. • Containers on official node images from 22.20 and 24.5 are PQ with no change. Below that, bump the tag. • Distro Node from dnf follows the system OpenSSL, so it needs the system config file or DEFAULT:PQ, like Python. • The pitfall to scan for: code or NODE_OPTIONS capping TLS at 1.2. • EKS not run in the emulator; same images as ECS.
