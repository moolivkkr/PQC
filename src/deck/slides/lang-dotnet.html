KEY MESSAGE: .NET on Linux uses the OS OpenSSL, so the image tag is the fix for containers and one config file is the fix for Lambda and EC2. • Lambda dotnet8 and dotnet10: the same config file as Python, in the layer or the package. • Containers: the default Microsoft tags are Ubuntu 24.04 or Debian 12 with OpenSSL 3.0, so not PQ. The Alpine and 10.0-resolute tags are PQ out of the box. • AL2023 images and hosts: OPENSSL_CONF or DEFAULT:PQ, as for Python. • .NET has no API to choose TLS groups, so there is no code fix; teams change the image or the config. • Windows Schannel supports the hybrid group as an opt-in; documented by Microsoft, not tested here. • EKS not run in the emulator; same images as ECS.
