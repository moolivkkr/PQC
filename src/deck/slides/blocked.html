KEY MESSAGE: Some legs can’t be PQ until AWS ships support. We name them, protect them another way, and recheck them, so they never hide inside a “done” number. • CloudFront to origin, API Gateway HTTP and WebSocket APIs and egress, IoT Core, Network Firewall TLS inspection and AWS VPN, and the managed data services. • Each gets an exception ID that every guardrail recognises: the same ID is a tag in Terraform and CloudFormation and an annotation in Kubernetes. • Each records the data on that path and how long it must stay confidential, because that is the harvest-now risk. • 90 days at most, 180 for vendor-blocked items, no renewal without a new exit date.
