KEY MESSAGE: At the front door, PQ is a policy choice we control; the risk is drift, so the SCP and Config rule hold the line. • Load balancers: name the 2025-09 PQ policy. Infrastructure as code defaults to the 2016-08 classical policy; only the console defaults to PQ. • The leg from the load balancer to the target follows the target’s TLS, so the language fixes still matter behind a PQ listener. 32 e2e cases cover it. • CloudFront is PQ to viewers today; its origin leg and API Gateway HTTP and WebSocket APIs are blocked until AWS adds support. Fronting an HTTP API with CloudFront is the workaround, with its cost. • AWS endpoints: KMS, STS, IAM, ACM, S3, DynamoDB and Secrets Manager accept PQ. Our work is on the client. CloudTrail records keyExchange for several of them. • WAF never terminates TLS; whatever it is attached to decides. • All of this is from AWS documentation except the target-leg cases, which ran in the emulator. Nothing here ran on a real AWS account.
