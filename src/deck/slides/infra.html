KEY MESSAGE: At the edge most of the work is choosing the PQ policy; where AWS has no option, the leg is an exception, not a failure. • Load balancers and API Gateway REST: switch the policy. CloudFront is already PQ to viewers. • AWS endpoints: KMS, STS, IAM, ACM, S3 and DynamoDB accept PQ today. The work is on our client side, and CloudTrail proves KMS, STS, IAM, Secrets Manager and ACM calls. • Egress: Squid, Envoy and strongSwan 6.0.2+ can do PQ. An egress proxy carries calls from workloads that can’t upgrade yet. Zeek on traffic mirroring sees the group. • WAF never terminates TLS, so whatever it is attached to decides. • IoT Core has no PQ policy, so device connections stay classical until AWS adds one.
