Post-quantum TLS on AWS · 13 · AWS service support checked 2026-11-16

KEY MESSAGE: For the shared infrastructure, PQ is mostly choosing the right policy or version; the gaps are AWS’s, and we track them. • ALB, NLB and API Gateway REST: switch to the PQ security policy. CloudFront is PQ to viewers; the origin leg is still classical. • AWS endpoints we call most (KMS, STS, Secrets Manager, ACM, IAM) already accept PQ from a fixed client. • Meshes: Linkerd 2.19+ by default; Istio 1.27+ with the PQC compliance policy, which enforces PQ and breaks non-PQ peers. Meshes cover their own legs only, not app-originated TLS. Envoy is PQ by default from 1.40, and we tested 1.40.2. • Gaps: API Gateway HTTP and WebSocket APIs, and IoT Core. These are exceptions with a review date.
