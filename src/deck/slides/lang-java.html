KEY MESSAGE: Java ignores the OS, so the JDK decides: JDK 25 is PQ by itself, and JDK 8 to 21 need the kit until Oracle’s backport. • JSSE doesn’t use OpenSSL, so crypto policies and config files do nothing for Java. • Kit v2 adds the Bouncy Castle provider through JAVA_TOOL_OPTIONS: a layer on Lambda, an env var in the task definition, a systemd line on EC2. • Java 8 needs two extra flags; the layer adds them. • JDK 25.0.5 and later are PQ by default. Oracle says backports to 17 and 21 come in H1 2027; that’s a claim, not tested. • Main risk: the agent replaces the TLS provider for the whole JVM, so FIPS, custom keystore and mTLS services get tested first. • EKS not run in the emulator; same images as ECS.
