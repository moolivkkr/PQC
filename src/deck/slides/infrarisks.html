KEY MESSAGE: The infrastructure side had its own traps. Each would have produced a false “PQ” or a broken pipeline, and each is now handled. • The biggest: infrastructure as code defaults load balancers to a classical policy. Only the console defaults to PQ. • Security Hub’s ELB.17 control passes policies that aren’t PQ, so a green dashboard isn’t PQ coverage. • Debian’s GnuTLS has no ML-KEM, so wget and git fail against PQ-only servers. SSH is already PQ with OpenSSH 10. • Kyverno 1.20 removed the legacy policy type, so the admission rules are written in the new format. • Envoy 1.40+ is PQ by default; older Envoy needs ecdh_curves. • Our own guardrail rejected the guide’s bundled config path; all four rule sets were fixed and retested.
