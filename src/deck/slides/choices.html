Post-quantum TLS on AWS · 09

KEY MESSAGE: We keep the change small, reversible and provable, so it can go everywhere without a programme of certificate work. • Key exchange only: no certificate re-issue, no new PKI. Post-quantum certificates are a separate step for later. • Hybrid, never PQ-only: anything that can’t do PQ still connects, so nothing breaks on the day we switch. • The platform ships the fix in the shared build template; app teams release it. Rollback is removing one file or one variable. • Guardrails start in warn mode (about 30 days first, per the plan’s risk table) so teams aren’t blocked by a rule we got wrong. • And a workload is only done when a log shows X25519MLKEM768, not when the change merges.
